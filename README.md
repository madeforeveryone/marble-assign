# 마블 배정 룰렛

구슬 레이스로 **선생님 순위**를 정하고, 이어서 **학생 순위**대로 프로젝트에 자동 배정하는 추첨 앱입니다.
[lazygyu의 마블 룰렛](https://lazygyu.github.io/roulette/)에서 영감을 받았습니다.

## 사용법

1. 선생님 이름과 학생 이름을 한 줄에 한 명씩 넣습니다. (쉼표로 구분해도 됩니다)
2. **1단계 · 선생님 레이스** — 먼저 도착하는 순서로 1등, 2등 … 이 정해집니다.
3. **2단계 · 학생 레이스** — 학생이 도착하는 순서대로 1등 선생님부터 차례로 배정됩니다.
   예) 학생 20명 / 선생님 4명 → 1~5등은 1등 선생님, 6~10등은 2등 선생님 …
4. 결과 화면에서 **표 복사**(엑셀·시트 붙여넣기용) 또는 **텍스트 복사**로 가져갑니다.

- 배정 인원은 자동으로 고르게 나뉩니다(나머지는 앞 순위 선생님부터 1명씩 더). `직접 지정`에 `6,5,5,4`처럼 적으면 그대로 씁니다.
- 골 바로 앞에 **필터**(천천히 도는 긴 패들 + 구슬 1.8개 폭의 통로)가 있어 마지막 순위가 여기서 갈립니다. 다음에 들어올 구슬이 필터에 가까워지면 카메라가 **클로즈업**하고, 1등과 선생님이 바뀌는 등수(커트라인)에서는 **슬로모션**이 걸립니다. 마지막 한 명은 자동으로 확정됩니다.
- 레이스 중 `1× / 2× / 4×` 로 속도를 바꿀 수 있고, 효과음은 🔊 버튼으로 끄고 켭니다. 스페이스바로도 출발할 수 있습니다.
- 입력한 이름은 브라우저에 저장되어 다음에 다시 열어도 남아 있습니다.
- 서버가 필요 없는 정적 페이지라 GitHub Pages는 물론, `index.html`을 더블클릭해 `file://`로 열어도 동작합니다.

## 구조

```
index.html        화면
css/style.css     스타일
js/race.js        코스 · 물리(Matter.js 120Hz 고정 스텝) · 캔버스 렌더링
js/app.js         설정 → 1단계 → 2단계 → 결과 흐름, 효과음(WebAudio)
vendor/matter.min.js  Matter.js 0.20.0 (MIT)
tools/simulate.js     코스 시뮬레이션 (node tools/simulate.js [구슬 수] [횟수])
tools/qa_flow.py      브라우저 플로우 테스트 (Playwright)
```

### 코스 설계 메모

- 전원 완주가 보장되어야 하므로(꼴찌까지 순위가 쓰인다) 끼임이 생기지 않는 기하만 썼습니다.
  핀 간격·벽 간격은 구슬 지름(24px)보다 넉넉하고, 경사로는 벽과 60px 띄워 모서리 주머니를 없앴습니다.
- 그래도 1초 이상 거의 멈춰 있는 구슬은 살짝 밀어주고(`STUCK_MS`), 120초가 지나면 남은 구슬을 진행도 순으로 처리하는 안전장치가 있습니다.
  시뮬레이션 기준 20구슬 레이스에서 밀어주기는 평균 0.2회, 강제 처리는 0회입니다.
- 중력 0.7 기준 20구슬 레이스는 약 13초에 1등, 물리 시간 24초(슬로모션 포함 29초) 안팎에 끝납니다. 4구슬은 약 24초. 더 빠르게 보려면 속도 버튼을 쓰세요.
- 필터는 lazygyu 마블 룰렛 'Wheel of fortune' 맵의 골 구조를 구슬 크기 비율로 옮긴 것입니다: 45° 깔때기 → 폭 44px(구슬 지름 1.8배) 통로, 통로 입구 옆에 축을 둔 패들이 1.2 rad/s 로 돌며 입구 쪽 날개가 위로 올라가 구슬을 퍼 올립니다. 패들 반길이는 원작 비율(96px)이면 20명 레이스가 37초로 늘어져 80px 로 줄였습니다(시뮬레이션 24초).
- 클로즈업/슬로모션도 원작 방식입니다: 다음에 도착할 구슬이 입구에서 260px 안이면 줌(최대 2.1배)이 입구 구역을 고정 프레이밍하고, 커트라인 등수가 걸린 구슬이 입구 200px 안에 경쟁 구슬과 함께 있으면 최저 0.3배까지 느려집니다. 커트라인 한 번당 슬로모션은 실시간 3.5초까지만 걸어 레이스가 늘어지지 않게 했습니다.
- 회전체는 정적 몸체의 각도만 매 스텝 바꾸는 방식(`Body.setAngle(body, angle, true)`)이라 접촉 속도에 회전이 반영되어 구슬을 제대로 튕겨냅니다.

## 배포

- 사이트: https://madeforeveryone.github.io/marble-assign/
- GitHub Pages 는 `gh-pages` 브랜치(루트)에서 서빙됩니다. `main` 에 푸시하면 `.github/workflows/pages.yml` 이 `gh-pages` 를 같은 내용으로 갱신하므로 `main` 만 관리하면 됩니다.

## 테스트

```
node tools/simulate.js 20 100 1,5,10,15   # 코스 시뮬레이션 (마지막 인자: 커트라인 등수)
python3 tools/qa_flow.py          # 브라우저 플로우 (pip install playwright && playwright install chromium)
python3 tools/qa_live.py          # 배포된 사이트 스모크 테스트
```
